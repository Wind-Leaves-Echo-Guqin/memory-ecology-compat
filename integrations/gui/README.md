# 记忆生态 · 观测舱（integrations/gui）

记忆生态的**本地可操作驾驶舱**。GUI = "人类宿主的适配器"：与 hermes / dsh 适配器平级，
核心零改动，符合多宿主纪律——读通道对数据根**零写入**；写操作不自行实现任何逻辑，
全部经确认闸门后**子进程转交核心 CLI**（继承其审计与备份），动作前后记 `action_log.jsonl` 账本。

- 版本：v0.3.2（可操作驾驶舱；九视图 + 确认闸门 + 急救箱 + 快捷键/命令面板 +
  星图物理引擎 + 全屏巡航 + 托盘常驻 + 一键安装）

## 启动（多入口，全部相对路径，clone 到哪都能用）

```bash
python eco_gui.py                    # 命令行：默认 127.0.0.1:8788，自动开窗口
python setup_ecology.py              # 一键安装/设置（推荐首次使用）
```

- **`python setup_ecology.py`** —— 一键安装：环境体检（Python ≥3.10）→ 可选依赖引导
  （pywebview 原生窗口 / pystray+Pillow 托盘，缺失只提示不强制）→ 空闲端口探测（8788 起上扫）
  → 生成桌面双击入口 → **首跑自检**（无窗口起服务 → 请求 `/api/meta` → 校验后自动收工）。
  `--yes` 全自动（默认不装可选依赖）；`--no-desktop` / `--no-verify` 可跳过对应步骤
- **双击 `启动生态观测舱.cmd`** —— 探测 pythonw/pyw 后分离启动服务 + 开原生窗口；
  服务已在跑则只再开一个窗口（不产生第二个服务实例）
- **双击 `启动生态观测舱.pyw`** —— pythonw 直启无黑框；启动失败弹窗给出原因
- **`python install_desktop.py`** —— 按本机安装位置生成桌面双击入口（指针式：
  桌面 cmd 仅 `call` 仓库正式启动器，仓库更新自动生效；生成物勿提交）
- **`python eco_gui.py --tray`** —— 托盘常驻（需 pystray+Pillow，缺失时打印安装指引并正常起服务）：
  左键显示/隐藏窗口，右键菜单含「开机自启（✅/❌，写 HKCU Run，当前用户级、可逆、默认关）」
  与「退出（停止服务）」；开关落盘 `%APPDATA%\eco-gui\settings.json`
- **双击 `生态急救箱.cmd`** —— GUI 起不来时的自救：自检 → 修复 → 重启服务 → 开窗
  （端口/进程冲突、数据根与关键文件、eco.db/executions.db 完整性、检索 CLI、
  过期索引自动重建、陈旧锁清理；生产 cron 领地**只诊断并给修复命令，绝不动手**）

数据根定位链：`--root` 参数 > `MEMORY_ECOLOGY_ROOT` 环境变量 > 宿主默认根探测 > 仓库根兜底
（零个人路径硬编码）；检索 CLI 同链（`--scripts-dir` / `ECO_SCRIPTS_DIR` > 数据根 scripts/ >
发布树 `src/memory_ecology/`）。装有 `pywebview` 时开原生窗口，未装自动降级系统浏览器。

## 键盘与命令面板

| 快捷键 | 动作 |
|---|---|
| `g` + `d/m/e/s/l/c/t/h/a` | 跳转九视图（驾驶舱/记忆库/经验/星图/血缘/候选/时间线/体检/动作日志） |
| `?` | 快捷键参考浮层（再按 `?` 或 `Esc` 关闭；含"复制诊断信息"入口） |
| `/` | 聚焦检索框（空框时显示最近 5 条搜索历史，`↑↓` 回溯） |
| `Ctrl+K` | 命令面板：模糊匹配视图名/别名、全部写动作、常用操作（导出/诊断/色板/动画强度/轮询…） |
| `r` | 重新读取快照；`Esc` 关闭抽屉/浮层/闸门/面板；`Ctrl+Shift+F` 全屏巡航 |

写动作从命令面板触发时，仍走**闸门 → dry-run 预览 → 确认执行**同一条链，不绕过确认。
输入框内不抢键（`Ctrl+K`/`Esc` 除外）。

## 动画与长期观测

- **动画强度三档**：轻（仅淡入淡出）/ 中（过渡 + 数字计数 + 图表入场）/ 满（全部动效，默认）；
  系统 `prefers-reduced-motion: reduce` 优先于应用设置（低动效下星图同步收敛、粒子关闭）
- **星图物理引擎**（`static/js/viz/force.js`，零依赖）：电荷斥力 / 链接弹簧 / 碰撞检测 /
  中心引力 / alpha 退火（按真实时间衰减，约 5.7s 收敛）/ 拖拽惯性 / 向日葵螺旋入场爆散
- **粒子光晕**（`static/js/viz/particles.js`）：仅深空大屏与巡航模式激活，慢速机自动降粒子数
- **自动轮询**：默认 30 秒（15/30/60/关，可在命令面板切换，仅浏览器端；桌面窗口保持手动刷新）；
  数据无变化不重渲染，**浮动面板打开时不打断**；后台仍推送告警与桌面通知
- **全屏巡航**：状态栏「巡航」或 `Ctrl+Shift+F` 进入，两种模式可切换——
  ① 轮播九视图（每视图 5–60 秒可调，底部进度条）② 固定驾驶舱大屏（字号与卡片放大，
  适合监控电视/副屏）；进入即切深空色板，`Esc`/鼠标移动/任意键退出并恢复原色板

## 写操作与确认闸门

四类动作（立即配额挤出 / 写入门整合 / 经验候选采纳 / 技能孵化）+ cron 修复（重跑/固定模型）
+ 立即体检 + 索引重建。全部强制走统一闸门组件：弹窗（动作名/影响/回滚方式）→ 按钮下红色
小字警告 → 高风险需勾选"我已知晓风险" → "不再提醒"按动作类型记忆（状态栏可重置提醒）。
服务端仅绑 127.0.0.1，白名单动作表，前端不能传任意命令。

## 硬约束落地

- **读写分离**：读通道零写入（文件纯读、SQLite `mode=ro` 短连接、锁只看存在性）；
  写通道仅 `POST /api/action/*`（127.0.0.1）且每个动作=子进程调用核心 CLI
- **纯离线**：零 CDN / 零图标库；手写 SVG 与力导向。字体**自托管**（`static/fonts/`，
  Inter + Noto Sans SC，SIL OFL 许可，随包分发），不从外部拉取。拔网全功能可用
- **快照与口径诚实**：状态栏"数据截至 HH:MM:SS"；瞬时口径与近 7 天口径分列标注不混称
- **fail-open**：任何接口/检索失败 → 黄条提示 + 页面照常；连续失败自动切急救模式页
  （诊断 + 一键复制报告 + 重启指引）；服务异常落 `gui_error.log`（1MB 轮转）
- **旧内核兼容**：polyfill（CSS.escape 等）+ 能力检测降级，不放弃 pywebview 原生窗口用户
- **零新依赖**：Python stdlib + pyyaml（核心既有）；pywebview 可选；动效遵守 prefers-reduced-motion

## 已知边界

- **自动轮询**默认 30 秒（浏览器端）；桌面窗口为省资源保持手动刷新（可点 ⟳）
- **Three.js 3D 星图**：v0.3.2 评估后**暂不纳入主线**——原型页 `static/demo-3d.html` 保留在
  开发树（158 节点/185 边渲染 draw call ≈345、帧率充裕，但需 +1.27MB 库体与 WebGL 能力，
  旧 WebView 内核不保证可用；2D SVG 力导向已覆盖"看引用/血缘"核心任务）。发布树不含原型与库
- **托盘常驻**需 pystray + Pillow（可选依赖，`setup_ecology.py` 会引导安装）；缺失时托盘降级、
  其余功能不受影响；开机自启写当前用户级注册表项，随时可从托盘菜单关闭
- Hermes 专属动作（cron 重跑/固定模型）在未安装 hermes CLI 的机器上自动降级为"复制命令"
- GUI 自身不管理自己的升级；仓库启动器更新后桌面指针入口无需重新生成（`call` 转发）
