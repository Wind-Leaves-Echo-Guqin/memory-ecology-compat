# 记忆生态 · 观测舱（integrations/gui）

记忆生态的**本地可操作驾驶舱**。GUI = "人类宿主的适配器"：与 hermes / dsh 适配器平级，
核心零改动，符合多宿主纪律——读通道对数据根**零写入**；写操作不自行实现任何逻辑，
全部经确认闸门后**子进程转交核心 CLI**（继承其审计与备份），动作前后记 `action_log.jsonl` 账本。

- 版本：v0.3（可操作驾驶舱；九视图 + 确认闸门 + 急救箱 + 无障碍套件）

## 启动（三入口，全部相对路径，clone 到哪都能用）

```bash
python eco_gui.py                    # 命令行：默认 127.0.0.1:8788，自动开窗口
```

- **双击 `启动生态观测舱.cmd`** —— 探测 pythonw/pyw 后分离启动服务 + 开原生窗口；
  服务已在跑则只再开一个窗口（不产生第二个服务实例）
- **双击 `启动生态观测舱.pyw`** —— pythonw 直启无黑框；启动失败弹窗给出原因
- **`python install_desktop.py`** —— 按本机安装位置生成桌面双击入口（指针式：
  桌面 cmd 仅 `call` 仓库正式启动器，仓库更新自动生效；生成物勿提交）
- **双击 `生态急救箱.cmd`** —— GUI 起不来时的自救：自检 → 修复 → 重启服务 → 开窗
  （端口/进程冲突、数据根与关键文件、eco.db/executions.db 完整性、检索 CLI、
  过期索引自动重建、陈旧锁清理；生产 cron 领地**只诊断并给修复命令，绝不动手**）

数据根定位链：`--root` 参数 > `MEMORY_ECOLOGY_ROOT` 环境变量 > 宿主默认根探测 > 仓库根兜底
（零个人路径硬编码）；检索 CLI 同链（`--scripts-dir` / `ECO_SCRIPTS_DIR` > 数据根 scripts/ >
发布树 `src/memory_ecology/`）。装有 `pywebview` 时开原生窗口，未装自动降级系统浏览器。

## 写操作与确认闸门

四类动作（立即配额挤出 / 写入门整合 / 经验候选采纳 / 技能孵化）+ cron 修复（重跑/固定模型）
+ 立即体检 + 索引重建。全部强制走统一闸门组件：弹窗（动作名/影响/回滚方式）→ 按钮下红色
小字警告 → 高风险需勾选"我已知晓风险" → "不再提醒"按动作类型记忆（状态栏可重置提醒）。
服务端仅绑 127.0.0.1，白名单动作表，前端不能传任意命令。

## 硬约束落地

- **读写分离**：读通道零写入（文件纯读、SQLite `mode=ro` 短连接、锁只看存在性）；
  写通道仅 `POST /api/action/*`（127.0.0.1）且每个动作=子进程调用核心 CLI
- **纯离线**：零 CDN / 零 Web 字体 / 零图标库；手写 SVG 与力导向；系统字体栈。拔网全功能可用
- **快照与口径诚实**：状态栏"数据截至 HH:MM:SS"；瞬时口径与近 7 天口径分列标注不混称
- **fail-open**：任何接口/检索失败 → 黄条提示 + 页面照常；连续失败自动切急救模式页
  （诊断 + 一键复制报告 + 重启指引）；服务异常落 `gui_error.log`（1MB 轮转）
- **旧内核兼容**：polyfill（CSS.escape 等）+ 能力检测降级，不放弃 pywebview 原生窗口用户
- **零新依赖**：Python stdlib + pyyaml（核心既有）；pywebview 可选；动效遵守 prefers-reduced-motion

## 自定义

- 右上角色点换肤（五套浅冷色板 + 深空大屏）——换 token 不换语义色，localStorage 持久化
- 星图骨架/全图/列表模式、线型开关、分类筛选即点即生效；字号四档持久化

## 已知边界

- 快照语义：手动 ⟳ 刷新 + 状态栏快照时间，不做后台推送
- Hermes 专属动作（cron 重跑/固定模型）在未安装 hermes CLI 的机器上自动降级为"复制命令"
- GUI 自身不管理自己的升级；仓库启动器更新后桌面指针入口无需重新生成（`call` 转发）
